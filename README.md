# 坦克大战 · Battle City

一个用纯 HTML5 Canvas 实现的经典《坦克大战》网页游戏。**单文件、零依赖、即开即玩**——打开 `index.html` 就能开始游戏。

![游戏截图](screenshot.png)

## 玩法

- 操控己方坦克，守护地图右下角的**基地（鹰旗）**，消灭本关全部敌方坦克即可过关。
- 敌方坦克会不断出怪、移动、射击，并试图摧毁你的基地；**基地被毁**或**生命耗尽**即游戏结束。
- 地形规则：
  - 🧱 砖墙：可被击毁
  - ⚙️ 钢墙：坚不可摧（满级火力可摧毁）
  - 🌊 水塘：阻挡坦克，子弹可穿过
  - 🌿 草丛：隐藏坦克

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击 |
| P | 暂停 |
| M | 静音 |

移动端自动显示虚拟摇杆与射击按钮。

## 特色

- 5 个关卡循环推进，敌人逐关变强
- 4 种敌人：普通 / 快速 / 火力 / 重装（需多枪击毁）
- 5 种道具：⭐ 火力升级、坦克加命、护盾、手雷
- HUD 显示得分 / 最高分（本地保存）、生命、关卡、剩余敌人
- 音效由 Web Audio 实时合成，无需任何资源文件

## 运行

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

也可以部署到 GitHub Pages：仓库 **Settings → Pages → Source 选择 `main` 分支** 即可。
